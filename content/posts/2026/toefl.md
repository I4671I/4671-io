这个文档其实约一个月前考完托福就写好了，最近才想起来可以改一改然后上传到博客上面，又水了一篇文章属于是。本文适合有一定英语阅读、听力基础，平时没怎么写/说过英语且希望在1-2周内速通的同学。

注意事项：
1. 此文档不包含简单题型的详细介绍，最有用的是写作和口语模板。
2. 速通可以直接放弃写作、口语的话题积累。
3. 部分文档内容来源于[清北托福慕课](https://www.bilibili.com/video/BV1LW411v7Z6)。
4. 本人使用的刷题网站：[EasyTuofu](https://easytuofu.cn/homepage.php)，一个月58还带AI批改（口语会偏低）。
5. 建议练习时所有题都要严格计时。
6. 前三个版块做完都可以跳过剩余时间，建议做完检查完就跳过，口语部分受到的干扰会小一些。

## 阅读
- 包含：填词、日常阅读、学术阅读。
- 水，只要填词别错太多就能拿6分。可以返回改答案。

### 填词
- 建议10道题2min。
- 即使速通也建议在此期间背些单词，对此题型很有效，也可以通过做题积累。
- 如果填不出来了也建议蒙一个第一时间感觉不一定对的词上去，说不定就是对的。

## 听力
- 包含：选择回答、日常对话、通知公告、学术讲座。
- 水，别走神就能拿6分（走神一点也有可能拿6分，心态要稳住）。
- 听力部分无法返回改答案，每题放完音频后会有20-30s作答。
- 记笔记看个人习惯即可，本人习惯记笔记，没有任何问题。

## 写作
- 包含：造句填空、邮件写作、学术写作，对本人来说后面两部分时间相当有限。

### 邮件写作
- 总时间7分钟。
- 题目要求会给出需要你完成的三个任务。
- 总字数无要求，流畅写完即可。
- 对于一些可以实例化的地方尽量编一下，例如题目要求和老师某课程有关则应在文中写出一个编出来的课程名。

#### 邮件模板
```
1. 称呼 Dear ___,
2. 问候 I hope you are doing well.
3. 任务1
4. 任务2
5. 任务3
6. 感谢 Thank you very much for your time and assistance.（可灵活调整表达感谢）
7. 落款 Best regards,（直接抄即可，不需要加名）
```

### 学术写作
- 总时间10分钟。
- 流程：
  - 审题归纳 1min
    题目会出现的五段文字如下：
    ~~1. 题目要求（不用看）~~
    ~~2. 教授导入（不用看）~~
    3. 题目要求
    4. 学生A发言
    5. 学生B发言
  - 开始写作，要求不少于100词，建议大于135词 8m30s
  - 检查 30s

#### 学术模板
```
1. 让步认可一位同学的观点（短句）
    [Student] presents a convincing point about [old reason].
2. 让步认可的理由（短句）
    Admittedly, [old option] can [old benefit]. 
3. 转折提出自己的观点（短句）
    However, considering [higher standard], I think [your choice]. 
4. 给予新的支持理由（短句）
    In my opinion, [your choice] can [new reason]. 
5. 解释陈述（长句）
    In other words, [Explanation sentence with concrete features].
6. 例证细节（长句）
    For example, ...
7. 总结观点（短句）
    Therefore, I believe [new point].
```

## 口语
- 包含：复述题、面试题。

### 复述题
- 绝大部分人都无法完全还原原句（包括本人），语法的正确性和内容的完整性是重点。
- 如果没法记全，重点记WHW（Who How What，可能还有Where），句子可以不完全一致。

### 面试题
- 每题有45s作答，尽量说满。
- 得分原则：结构比内容重要；通用比新鲜重要；流畅比高级重要。
- 多加练习，即可像本人从45s里能卡住30s到接近流畅说满45s。

#### 面试题模板
- 有非常小部分不太适合用这个模板的题，如描述一次经历等，依据个人能力自由发挥即可。
```
1. 观点：I believe that __________.
2. 万能理由1：First, __________.
3. 举例论证1：For example, __________.
4. 万能理由2：Second, __________.
5. 举例论证2：For instance, __________.
6. 总结备用：So overall, __________.（没时间可以忽略）
```
#### 12个万能理由
- 推荐提前抄在纸上。
```
方便、效率
经济、耐久
安全、环保
交流、经验
乐趣、成就
情感、健康
```
